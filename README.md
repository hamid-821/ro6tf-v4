# RO6TF — اسکنر ورود کریپتو فیوچرز

سامانه‌ای برای اجرای خودکار استراتژی Pine Script «RO6TF PREMIUM BUY CONFIRMATION».

## نحوه کار
- هر ۶۰ ثانیه (قابل تنظیم) بازار فیوچرز را اسکن می‌کند (منبع پیش‌فرض: Bitget USDT-M Futures، ۷۹۷ نماد؛ منبع دوم: فید اسپات بایننس).
- هر نماد را با **نمره دهی** بر اساس ۴ قانون سیستم امتیاز می‌دهد:
  | قانون | وزن |
  |---|---|
  | کمان RSI (MA یصعوب‌شده) ۱ساعته رو به بالا | ۲ |
  | کمان RSI ۵دقیقه‌ای رو به بالا | ۲ |
  | کمان RSI ۱دقیقه‌ای رو به بالا | ۱ |
  | MACD ۵m سبز (هیستوگرام ≥ 0) | ۱.۵ |
  | ADX ۵m بالای ۲۳ (بین ۲۰–۲۳ نمره ناقص) | ۱.۵ |
  | LIQ ۵m سبز (PIVOT حمایتی فعال) | ۱ |
  | LIQ ۱m سبز (PIVOT حمایتی فعال) | ۱ |
- روی هر نماد کلیک کن → پنل کامل: وضعیت هر فیلتر با اعداد دقیق + نمودار خط RSI (صورتی) و MA (زرد) در هر سه تایم‌فریم + نمودار هیستوگرام MACD + نمودار قیمت/EMA ۵m + سطوح نقدینگی و PA + رأی نهایی:
  - ✅ **ورود** — همه فیلترها سبز
  - ⏳ **صبر** — با لیست دقیق موارد باقی‌مانده
  - ❌ **ناورود** — با دلیل رد (مثلاً ADX < 20)

## محاسبات
- همه اندیکاتورها (RSI/MACD/ADX/Stoch-RSI/NWE/Range-Osc/PIVOT/Swing-PA) دقیقاً با منطق Pine Script و روی **شمع بسته** محاسبه می‌شوند (بدون ریپینت).
- سرویس‌دهنده: Node.js بدون وابستگی (`server.js` + `lib/indicators.js`)، پورت 8000.
- APIهای استفاده‌شده: `api.bitget.com` (فیوچرز) و `data-api.binance.vision` (اسپات بایننس).

## محدودیت‌ها
- API فیوچرز بایننس (fapi) از سرور این محیط مسدود است (کوئید 451)؛ از این رو داده فیوچرز از Bitget و داده تیکرهای بایننس از فید اسپات آن می‌آید (قیمت‌ها تقریباً یکسان).
- نمادهایی که فقط فیوچرز بایننس دارند و در هیچ منبع دیگری نیستند (مثلاً 4USDT) قابل بررسی نیستند.
- خروجی ابزار، کمک فنی است نه توصیه مالی.
